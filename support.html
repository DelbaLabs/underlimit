UnderLimit Support

Need help with UnderLimit? This page covers common questions about photo compression, PDF compression, free usage and UnderLimit Unlimited.

Photo compression

UnderLimit can reduce supported photos to a selected maximum file size. You can choose a preset limit or enter a custom value.

Smart Analysis may recommend keeping the original file when further compression would provide little benefit.

PDF compression

UnderLimit analyzes a PDF before compression and can recommend a suitable target size.

Preserve Text mode prioritizes searchable and selectable text. Strong Compression prioritizes smaller file size and may convert PDF pages into optimized images, which can remove some interactive PDF features.

Free usage

UnderLimit includes an initial free compression allowance. After the initial allowance has been used, one free compression is available each day.

A compression is counted only after a real compression operation completes successfully.

UnderLimit Unlimited

UnderLimit Unlimited is a one-time in-app purchase that removes compression limits for both Photo and PDF tools.

It is not a subscription.

Restore Purchases

If you previously purchased UnderLimit Unlimited with the same Apple Account, open the Unlimited screen in the app and use Restore Purchases.

Privacy

Photo and PDF processing is performed locally on your device. Your selected files are not uploaded to a compression server.

For more information, read the UnderLimit Privacy Policy.
